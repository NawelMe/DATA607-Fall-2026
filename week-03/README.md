# DATA 607 – Week 3

This folder contains my Week 3 assignments for DATA 607.

## Assignment 3A: Global Baseline Estimate Recommender

This assignment uses R to create a Global Baseline Estimate recommender and predict missing movie ratings using the global average, movie bias, and critic bias.

## Assignment 3B: Window Functions on Stock Prices

This assignment uses SQL and R to calculate year-to-date averages and six-day moving averages for AAPL, MSFT, and NVDA stock prices. The SQL results are compared with calculations completed in `dplyr`.
