# DATA 607 — Project 1

CUNY SPS, Fall 2026. Parses `tournamentinfo.txt` (a chess tournament cross-table) into a CSV with each player's name, state, total points, pre-rating, and average pre-rating of opponents faced.

- [`project1.Rmd`](project1.Rmd) — full parsing + analysis
- [`tournament_results.csv`](tournament_results.csv) — output, generated by the .Rmd (committed here too for convenience)
